# Geo Measure

Geo Measure is a mobile-friendly learning website for Grade 11 geometry and measurement. It offers 18 guided lessons, interactive diagrams, formula references, practice questions, progress tracking, and six educational games.

Lessons include pre-generated Luna narration with synchronized sentence highlighting. The saved audio plays directly in the browser; it does not require live speech generation, a TTS service, or a downloaded voice model.

The website is built with Next.js and React. Learning progress and preferences are stored in the learner's browser.
