`chibi-trio.png` is a transparent 1536 × 1024 PNG generated with the built-in ImageGen tool from the two original sheets in `/Mascot`. Character order is Luna, Nori, Mimi. The originals are retained.

The characters are rendered with individual background regions in `Mascot.tsx` and `experience.css`. Nori's region includes the complete waving paw; Mimi's region starts after it so no cyan fragment appears beside her. Keep these regions if replacing the artwork with the same sheet.
